1. What you need

  • A microSD card, ideally 16 GB or bigger, and a card reader in your computer.
  • A computer with Windows 10/11, macOS or Linux, connected to the internet.
  • A Xiegu X6100 radio.
Warning: writing erases the whole card. If there is anything important on it, copy it to your computer first. The app does not touch the original system in the radio's internal memory.

2. Starting the app

Download it from the release page (Releases), at the very bottom under Assets.

Windows

  1. Download Xiegu-Multi-Patcher-Windows.zip.
  2. Right-click the file → Extract All… → Extract.
    Don't run the program straight from the .zip file; it won't work.
  3. In the extracted folder, double-click Xiegu Multi Patcher.exe.
  4. If a blue “Windows protected your PC” window appears: click More info → Run anyway. The app has no paid signature, so Windows doesn't “know” it.

macOS

  1. Download Xiegu-Multi-Patcher-macOS.zip and double-click it to unpack it.
  2. Drag Xiegu Multi Patcher to the Applications folder and open it.
  3. If macOS blocks it: System Settings → Privacy & Security → at the bottom Open Anyway.

Linux

  1. Download Xiegu-Multi-Patcher-Linux.zip and unpack it.
  2. In the Xiegu Multi Patcher folder, run the Xiegu Multi Patcher file (double-click, or in a terminal ./"Xiegu Multi Patcher"). If it won't start: chmod +x "Xiegu Multi Patcher".

Change the language at the top right of the window (Polski / English).

3. Your first card: the radio's systems

  1. Click + From the internet….
  2. Choose OpenX6X00 (the newest version is already selected) and click Add. The app downloads the system by itself; the progress shows at the bottom of the window.
  3. If you like, add other systems the same way (OpenX6100, CX8ANM, 1KO125, IU1WXY, R1CBU). Up to 5 entries in all.
    Advanced: at the bottom of that window, under your own GitHub repository, type another repository (e.g. owner/repo) and click Add the repository. Its versions are listed like the other systems.
  4. To have the original Xiegu system from the radio's memory in the menu too, click + Xiegu from eMMC.
  5. The window shows the menu exactly as the radio will. Click a tile to select it, then:
    • the arrows ← → change the order,
    • ★ Default: this system starts by itself if you press nothing,
    • Rename and Logo…: your own label and picture (optional).
  6. Put the card in the reader. Choose it in the SD card list (not there? click Refresh). Check the card's size so you don't pick another disk by mistake.
  7. Click Write to the card, confirm, and enter your computer's password if asked.
  8. Wait for ✓ Done. After writing, the app checks the card; this takes a few minutes, don't interrupt it.
Important for Doom and the emulator: keep OpenX6X00 first among the systems. Doom and the emulator use its kernel, Bluetooth and WiFi.
Already have a card with the radio's settings? Put it in before writing and leave Carry the settings over from the old card ticked. The app copies the settings, logs and pairings and, after writing, puts them back into the same systems.

4. Starting the radio from the card

  1. Put the card in the radio (with the radio off) and switch it on.
  2. A menu with tiles appears. Choose a system with the F1–F5 keys under the screen (F1 is the first tile from the left).
  3. If you press nothing, the default system (★) starts after a few seconds.
  4. POWER in the menu switches the radio off.

The first start of a system can take longer than usual while it prepares the card.

5. Doom

Adding it

  1. First add a system (e.g. OpenX6X00), as in step 3.
  2. In the Extras part, click + Doom. A Doom tile appears in the menu.
  3. Write to the card.

6. The NES emulator and games

Adding it

  1. First add a system (preferably OpenX6X00), as in step 3.
  2. In Extras, click + NES emulator.
  3. Click NES games…. Add games with + Games… (single files) or + Folder… (a whole folder), then Done. Files: .nes, .fds, .unf, .nsf, also inside a .zip.
  4. Write to the card.
The app contains no games. You add your own copies.

Adding games later

  • From a computer: put the card in the reader. A BOOT disk appears; copy the games to its NES folder.
  • Over WiFi: see step 8 (no need to take the card out).
  • Covers: a .png or .jpg picture with the same name as the game shows next to the games list.

The emulator's menu

Tiles: Games, Controls, Bluetooth, WiFi, Off. Move around with the MFK knob or the d-pad. F1 or pressing MFK confirms, F2 goes back.

7. Pads, keyboard and mouse

By cable (USB)

Plug into the radio's HOST socket. Two devices at once: through a small USB hub. Nothing to switch on; it works straight away, even during a game. Wired Xbox 360 pads don't work (the radio has no driver for them).

A Bluetooth pad in the NES emulator (Xbox, PS4, 8BitDo, Switch)

  1. In the emulator's menu, choose the Bluetooth tile → Look for and pair new.
  2. Put the pad in pairing mode:
    • Xbox: switch the pad on, then hold the small pairing button on its front until the logo flashes fast.
    • PS4: hold Share and PS together until the light bar flashes.
    • 8BitDo: D-input or Switch mode, then hold the pairing button about 3 s.
  3. The pad appears in the list. Choose it (MFK or F1) and wait a few seconds until it connects. Keep the pad in pairing mode meanwhile.
  4. Done. Next time, just switch the pad on; it connects by itself.

The first pad is player 1, the second player 2. A different button layout: Controls → Pad buttons: a layout of your own. To switch a pad off, hold Home about 1 s (a menu appears: switch the pad off / switch the radio off). Pads switch off by themselves when the emulator closes.

A Bluetooth keyboard and mouse in the NES emulator

Same as a pad: Bluetooth → Look for and pair new. If a code appears on the screen, type it on the keyboard and press Enter.

A Bluetooth keyboard and mouse in Doom

  1. Start OpenX6X00 (the first system on the list) on the radio and pair the mouse and keyboard there: Settings → Bluetooth → DEVICES.
  2. Switch the radio off and start Doom.
  3. Move the mouse or press a key; they connect by themselves within about a minute.

8. WiFi: games from a browser, and updates

  1. In the emulator's menu, choose the WiFi tile → Connect to a network.
  2. Choose your network and type the password on the on-screen keyboard (the VFO or MFK knob moves over the letters, pressing MFK or F1 types a character, F2 deletes, choose OK at the end). You can also type it on a USB/Bluetooth keyboard.
  3. Once connected, the screen shows a QR code and an address, e.g. http://192.168.0.112/.
  4. Scan the code with a phone, or type the address in a computer's browser on the same network. Type it with http://, not https://.
  5. On the page (it is in Polish): + Pliki (files) or + Folder adds games to the list, − Usuń (remove) takes them off the list, and Wgraj do emulatora (upload) sends them to the radio. The games are in the Games list straight away.

The radio remembers the network and connects by itself next time. Show the QR code again from the WiFi menu.

Updating the emulator

  1. WiFi → Update the emulator. The radio checks for a newer version and downloads it.
  2. After writing it, the radio switches itself off. Switch it on and start the emulator.
Don't switch the radio off during the update. Your games and saves stay.
